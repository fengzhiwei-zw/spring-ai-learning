### 阶段 3：Prompt 工程 & 结构化输出

#### 一、Prompt 模板化：告别字符串拼接

在阶段 2 中，我们用的是简单的字符串传参：`.user("你好")`。但在实际开发中，提示词往往很长，且包含动态变量。如果用 `+` 号拼接字符串，代码会变得极难维护。

Spring AI 底层使用 **StringTemplate** 引擎，支持用 `{variable}` 占位符。

**1. 内联模板（适合短文本）**

在 `.user()` 或 `.system()` 中直接传入模板字符串和变量 Map：

```java
@GetMapping("/translate")
public String translate(@RequestParam String text, @RequestParam String lang) {
    return chatClient.prompt()
            .system("你是一位资深翻译专家")
            .user("请将以下文本翻译成{language}，只返回翻译结果，不要解释：\n{text}",
                  Map.of("language", lang, "text", text))
            .call()
            .content();
}
```

**2. 外部文件模板（适合长文本，⭐ 生产推荐）**

当提示词超过 10 行时，强烈建议将其放到 `src/main/resources/prompts/` 目录下。

创建文件 `src/main/resources/prompts/code-review.st`：
```text
你是一位拥有10年经验的Java架构师。
请对以下代码进行 Code Review。

要求：
1. 指出潜在的 Bug 和性能问题
2. 提供重构建议
3. 语气要专业、客观

代码语言：{language}
代码内容：
---
{code}
---
```

在代码中读取并使用：

```java
import org.springframework.ai.chat.prompt.PromptTemplate;
import org.springframework.core.io.ClassPathResource;

@GetMapping("/review")
public String reviewCode(@RequestParam String code) {
    // 1. 加载模板文件
    var template = new PromptTemplate(new ClassPathResource("prompts/code-review.st"));
    
    // 2. 注入变量生成 Prompt 对象
    Prompt prompt = template.create(Map.of(
        "language", "Java",
        "code", code
    ));
    
    // 3. 调用模型
    return chatClient.prompt(prompt).call().content();
}
```

> 💡 **最佳实践**：将提示词与代码分离，方便非技术人员（如产品经理、提示词工程师）在外部文件中调优 Prompt，而无需重新编译 Java 代码。

#### 二、结构化输出（Structured Output）⭐ 核心重点

**痛点场景**：
假设你要开发一个"书籍推荐"接口，前端需要渲染一个表格。如果模型返回一段自然语言（"我推荐《三体》，作者是刘慈欣..."），你还得用正则表达式去抠数据，这非常脆弱且容易报错。

**解决方案**：
Spring AI 的**结构化输出**功能，会根据你定义的 Java 类（POJO 或 Record）**自动生成 JSON Schema** 注入到 Prompt 中，强制模型返回符合该 Schema 的 JSON，并**自动反序列化**为 Java 对象。

**1. 基础用法：单对象映射 `.entity(Class)`**

推荐使用 Java 21 的 `record` 来定义数据结构：

```java
// 定义目标数据结构
public record BookRecommendation(
    String title, 
    String author, 
    int publishYear, 
    String genre, 
    String reason
) {}
```

调用时只需加上 `.entity()`：

```java
@GetMapping("/book")
public BookRecommendation recommendBook(@RequestParam String topic) {
    return chatClient.prompt()
            .user("推荐一本关于{topic}的经典书籍", Map.of("topic", topic))
            .call()
            .entity(BookRecommendation.class); // 自动解析为 Java 对象
}
```

访问 `/book?topic=微服务`，你将直接得到一个强类型的 Java 对象：
```json
{
  "title": "微服务架构设计模式",
  "author": "Sam Newman",
  "publishYear": 2021,
  "genre": "计算机科学",
  "reason": "本书详细阐述了微服务的设计原则和模式..."
}
```

**2. 集合与泛型映射 `.entity(ParameterizedTypeReference)`**

如果模型需要返回一个**列表**，由于 Java 的泛型擦除机制，你不能直接传 `List<Book>.class`。需要使用 Spring 提供的 `ParameterizedTypeReference`：

```java
@GetMapping("/books")
public List<BookRecommendation> recommendBooks(@RequestParam String topic, @RequestParam int count) {
    return chatClient.prompt()
            .user("推荐{count}本关于{topic}的经典书籍", 
                  Map.of("topic", topic, "count", count))
            .call()
            .entity(new ParameterizedTypeReference<List<BookRecommendation>>() {});
}
```

**3. Map 映射**

如果不需要严格的类定义，只想返回一个键值对：

```java
Map<String, Object> result = chatClient.prompt()
        .user("提取这段文本中的关键实体和对应的值：马斯克收购了推特")
        .call()
        .entity(new ParameterizedTypeReference<Map<String, Object>>() {});
// 返回: {"人物": "马斯克", "事件": "收购", "公司": "推特"}
```

#### 三、结构化输出的自纠错（Self-Correction）⭐

这是 Spring AI 2.0 的一个杀手级特性。

**场景**：模型有时候会"幻觉"，返回的 JSON 缺少必填字段，或者格式不对。
**解决方案**：结合 **Jakarta Bean Validation**（如 `@NotNull`, `@Size`, `@Min`）。当框架发现模型返回的数据校验不通过时，**不会直接抛异常，而是自动将校验错误信息回传给模型，要求它重新生成**，直到合规为止。

**1. 引入依赖**

在 `pom.xml` 中添加 Validation 依赖：
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-validation</artifactId>
</dependency>
```

**2. 添加校验注解**

```java
import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;

public record ProductInfo(
    @NotBlank(message = "商品名称不能为空") 
    String name,
    
    @Min(value = 0, message = "价格不能为负数") 
    @Max(value = 999999, message = "价格不能超过999999") 
    double price,
    
    @NotBlank(message = "分类不能为空") 
    String category
) {}
```

**3. 触发自动纠错**

在当前项目使用的 Spring AI 2.0.0 中，需要显式开启 Schema 校验及有限次数的反馈重试。添加 Validation 依赖或 DTO 注解本身不会自动启用这条链路：

```java
ProductInfo product = chatClient.prompt()
        .user("提取商品信息：这台二手手机只要50块钱")
        .call()
        .entity(ProductInfo.class, spec -> spec.validateSchema());

// validator 是注入的 jakarta.validation.Validator。
// Schema 检查和 Java 业务约束校验不能相互替代。
if (product == null || !validator.validate(product).isEmpty()) {
    throw new IllegalStateException("模型输出未通过业务校验");
}
```

纠错次数有限，不能保证模型最终一定返回合法数据。实际接口应处理重试耗尽和解析错误；当前 Controller 将无效模型输出转换为 502。对必须提取到的数字字段，使用带 `@NotNull` 的包装类型，避免字段缺失时被基本类型的默认零值掩盖。

#### 四、多模态输入（Multimodal）

现在的模型不仅能看懂字，还能看懂图。Spring AI 支持在 UserMessage 中混合传入文本和图片资源。

**1. 识别本地或网络图片**

```java
import org.springframework.util.MimeTypeUtils;
import org.springframework.core.io.ClassPathResource;

@GetMapping("/image/analyze")
public String analyzeImage() {
    // 加载 classpath 下的图片
    var imageResource = new ClassPathResource("images/demo.png");
    
    return chatClient.prompt()
            .user(u -> u
                .text("请用中文详细描述这张图片里的内容，包括人物、动作和环境")
                .media(MimeTypeUtils.IMAGE_PNG, imageResource) // 注入图片
            )
            .call()
            .content();
}
```

**2. 识别 Base64 图片（适合前端上传）**

```java
@PostMapping("/image/analyze-base64")
public String analyzeBase64(@RequestBody String base64Image) {
    // 假设前端传来的是 "data:image/jpeg;base64,/9j/4AAQ..." 或纯 Base64 字符串
    byte[] imageBytes = java.util.Base64.getDecoder().decode(base64Image);
    
    return chatClient.prompt()
            .user(u -> u
                .text("这张图片里有什么？")
                .media(MimeTypeUtils.IMAGE_JPEG, imageBytes)
            )
            .call()
            .content();
}
```

> ⚠️ **注意**：多模态功能依赖于底层模型的支持。如果你使用的是 Ollama，请确保拉取的是支持视觉的模型（如 `llava` 或 `qwen2.5-vl`），普通的 `qwen2.5:7b` 无法识别图片。

#### 五、完整实战代码整合

把阶段 3 的核心能力整合到一个 Controller 中：

```java
package com.example.demo;

import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.Min;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.prompt.Prompt;
import org.springframework.ai.chat.prompt.PromptTemplate;
import org.springframework.core.ParameterizedTypeReference;
import org.springframework.core.io.ClassPathResource;
import org.springframework.util.MimeTypeUtils;
import org.springframework.web.bind.annotation.*;

import java.util.List;
import java.util.Map;

@RestController
@RequestMapping("/api/v3")
public class Stage3Controller {

    private final ChatClient chatClient;

    public Stage3Controller(ChatClient chatClient) {
        this.chatClient = chatClient;
    }

    // 1. 外部模板文件调用
    @GetMapping("/review")
    public String reviewCode(@RequestParam String code) {
        var template = new PromptTemplate(new ClassPathResource("prompts/code-review.st"));
        Prompt prompt = template.create(Map.of("language", "Java", "code", code));
        return chatClient.prompt(prompt).call().content();
    }

    // 2. 结构化输出 - 单对象
    public record Book(String title, String author, int year, String reason) {}

    @GetMapping("/book")
    public Book getBook(@RequestParam String topic) {
        return chatClient.prompt()
                .user("推荐一本关于{topic}的书", Map.of("topic", topic))
                .call()
                .entity(Book.class);
    }

    // 3. 结构化输出 - 列表泛型
    @GetMapping("/books")
    public List<Book> getBooks(@RequestParam String topic, @RequestParam int count) {
        return chatClient.prompt()
                .user("推荐{count}本关于{topic}的书", Map.of("topic", topic, "count", count))
                .call()
                .entity(new ParameterizedTypeReference<List<Book>>() {});
    }

    // 4. Schema 反馈重试示例；实际接口还需显式执行业务校验
    public record StockInfo(
            @NotBlank String ticker,
            @Min(0) double price
    ) {}

    @GetMapping("/stock")
    public StockInfo getStock(@RequestParam String text) {
        return chatClient.prompt()
                .user("提取文本中的股票代码和价格：{text}", Map.of("text", text))
                .call()
                .entity(StockInfo.class, spec -> spec.validateSchema());
    }

    // 5. 多模态：图片理解
    @GetMapping("/image")
    public String analyzeImage() {
        return chatClient.prompt()
                .user(u -> u.text("描述这张图片")
                        .media(MimeTypeUtils.IMAGE_PNG, new ClassPathResource("images/demo.png")))
                .call()
                .content();
    }
}
```
